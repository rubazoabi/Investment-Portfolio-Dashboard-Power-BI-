# Investment-Portfolio-Dashboard-Power-BI-
This project presents an interactive Power BI dashboard for analyzing investment portfolio performance,
including returns, benchmark comparison, asset allocation, and risk exposure.
The dashboard enables users to explore financial data and gain insights into portfolio profitability,
strategy effectiveness, and performance relative to market indices.

---

## Key Features

- Portfolio return and profit analysis
- Benchmark comparison (Portfolio vs Market)
- Alpha (excess return) calculation
- Asset-level performance analysis
- Allocation vs target weight analysis
- Risk and exposure insights
- Interactive filtering (portfolio, asset, year)

---

## Dashboard Pages

### 1. Main Overview
- Summary of portfolio performance
- Profit, dividends, invested capital
- Portfolio return %

### 2. Benchmark Comparison
- Portfolio vs market return
- Alpha analysis
- Performance status (Outperform / Underperform)

### 3. Allocation Analysis
- Asset allocation vs target weights
- Asset return comparison
- Risk and exposure insights

### 4. Conclusions
- Key insights on performance, allocation, and strategy
- Benchmark comparison summary
